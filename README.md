## 💼 Experience

### 🤖 AI Project Lead · Mashabim Insurance Agency
**07/2026 – Present**

Lead the agency's AI projects, building AI agents that automate finance workflows.

**Commission Reconciliation System** — Python, ~40 modules
- Reads commission and production reports from **14 insurers and investment houses**
- Identifies every file **by its content, not its name** — renamed or reformatted reports are still read correctly
- Consolidates everything into **one fact table**, so every output agrees with every other
- Reconciles expected commissions against insurer ledgers and bank deposits, month by month
- Main product: an **interactive 11-screen dashboard**, with three key layers:
  - **Home page** — a coverage map: which reports arrived for each entity, insurer and month
  - **Overview** — all figures by insurer and agent number, with drill-down
  - **Campaign tracking** — tiered, year-cumulative insurer campaigns: how much is missing to each bonus target

**Monthly Commission Details** — semi-automated monthly download of reports from insurer portals, adding that month's commission-detail sheet to the master workbook.

> The code and data belong to the agency and are not public.

**Stack:** Python · Excel · HTML/JavaScript · AI Agents · MCP
